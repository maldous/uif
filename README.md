# UIF

UIF provides shared physical and virtual infrastructure and cross-project build, maintenance and delivery capabilities.

## Work management

[Linear](https://linear.app/maldous) is the authoritative source for work, scope, ownership, dependencies and acceptance. Stokowski selects and processes eligible Linear issues across the configured projects.

Original scope mappings and migration provenance are retained in [UIF-116](https://linear.app/maldous/issue/UIF-116) and Git history.
