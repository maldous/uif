## Required per-unit profile

Before a unit executes or transfers, resolve its canonical issue, accountable owner, stage, repository/base/head/tree/acquisition, allowed paths, workspace/resource lease, execution route and normal user, toolchain/fixed checks, rights/privacy, review/output and publication authority, original operation and recovery contract. Record missing inputs as unknown. A repository clone or project association supplies none of the missing grants.

Use one common procedure with project-specific facts. Do not build four custom bridges or erase product holds to make profiles look uniform. Wrong-project/repository/source/path/tool/rights and conflicting ownership must refuse before effects.
