# Native publication metadata adapter

This source implements a typed metadata handoff and original-receipt binding only. It has no file/network/subprocess/OAuth/credential access and NO publish/deploy action. This canonical source addition does not itself install or deploy a service and does not satisfy the outstanding production connector by itself. Exact module418f8f8d is separately exposed as the pure Foo publication_handoff metadata interface, not a production publisher. Do not add it as a blanket release gate.

A complete handoff binds project/route, original operation identity, full Git commit/tree OR full generated-snapshot digests, artifact digest/size, private destination/publisher references and bounded evidence references. References are not trusted grants or acceptance flags. The actual caller must resolve them through authorized sources, verify artifact bytes, current sole-publisher authority, original effects, applicable accepted review/checks/rights and exact native destination immediately before calling the already-authorized native publisher. Metadata cannot confer permission or clear a hold.

A real publish action requires invoking the existing native operation and reading its exact terminal receipt plus live postconditions.
