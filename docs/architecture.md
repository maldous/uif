# Architecture and actual interfaces

As of 6 November 2026, Melbourne. The foundation is shared; authority and evidence remain attached to their actual owners and projects.

## Two modes

Local mode uses the normal Foo local session-based Codex harness when tokens are available. MCP mode uses Morgan/native agents through Foo MCP when local Codex tokens are unavailable. They share Linear issue identity, source/evidence bindings and acceptance methodology. Current MCP foundation work is authorized independently of deferred local-mode BAU. Actual admission and evidence origin must remain truthful in either mode.

## Temporary execution boundary

Temporary native execution must retain its true origin, exact source and permissions. The reviewed-source and read-only routes already exist, but their applicability must be qualified against the selected unit. The source-outcome finalizer is narrower: it directly calls completed-native evidence and native journal acceptance. This is an unresolved integration boundary, not proof that arbitrary subagent output is accepted unchanged.

Do not fabricate a pool lease, native session or model resolution to cross that boundary. Inspect the actual producer, handoff schema and selected consumer; use an existing supported origin when it fits, or make a separately reviewed minimal correction under UIF-161. No runtime correction is delivered by these documents.
